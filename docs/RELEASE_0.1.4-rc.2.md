# v0.1.4 Patcher fix and performance

This prerelease fixes installation from the PowerShell script.

- Running the script without options now installs instead of only checking status.
- A healthy older v6 install now upgrades to the v11 patch automatically.
- QUICKSTART is shorter. The mod bridge and compatibility checks are still included.

Download `KD-Hybrid-0.1.4-rc.2-setup.zip`, unzip it, and follow `QUICKSTART.txt`. Close the game before installing. Experimental magic-event skipping remains off and is not selectable in this build.
