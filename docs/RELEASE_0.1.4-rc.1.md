# v0.1.4 Performance and mod compatibility

This is a prerelease for Kinky Dungeon 5.4.92.

- Adds the tested v11 CPU patch for the official game bundle.
- Keeps the mod bridge and compatibility checks from v0.1.2.
- Experimental magic-event skipping stays off. It is not exposed as a setting in this combined build.
- The installer keeps a backup, and uninstall restores the original game files.

Download `KD-Hybrid-0.1.4-rc.1-setup.zip` and follow `QUICKSTART.txt` inside it. If you already have an older Rusted Kinks core installed, uninstall it before installing this prerelease. The v0.1.3 add-ons remain separate downloads.
