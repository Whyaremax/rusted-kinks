KD Hybrid quick start
=====================

Unzip this folder. Right-click KDHybrid-Patcher.ps1 and choose "Run with
PowerShell." Enter your Kinky Dungeon folder when asked, and you're done.
Close the game first. Node.js 22 or newer is required.

OPTIONS

To use parameters, open PowerShell in this folder. Example:

  .\KDHybrid-Patcher.ps1 -Action Status -GameRoot "C:\Path\To\Kinky Dungeon"

-Action Install      Install or upgrade. This is the default.
-Action Status       Check which version is installed.
-Action Configure    Change settings on an installed game.
-Action Uninstall    Remove Rusted Kinks.
-GameRoot            Path to the game folder. Omit to be prompted.
-PathfindingMode     fast (default), quality, or human.
-TextureMode         auto (default), original, full, or mobile.
-SourceMode          optimized (default) or original.
-NoSourceOptimizations  Same as -SourceMode original.

For example, to select the original source later:

  .\KDHybrid-Patcher.ps1 -Action Configure -GameRoot "C:\Path\To\Kinky Dungeon" -SourceMode original

Restart Kinky Dungeon after changing settings. This kit supports the exact
Kinky Dungeon 5.4.92 game build; other builds are refused.
