KD Hybrid quick start
=====================

This kit does not include Kinky Dungeon. Obtain the game separately from its
official distribution. Exact KD 5.4.92, 5.5.1 and 5.5.6 builds are supported.

OPTIONAL EARLY BOOTSTRAP PATCH

Requires Node.js 22 or newer.

Open PowerShell in this folder and run:

  .\KDHybrid-Patcher.ps1 -Action Install -GameRoot "C:\Path\To\Kinky Dungeon"

The default texture mode is `auto`, which selects KD's official mobile atlas
on the supported build. You can instead install with `original`, `full`, or
`mobile`:

  .\KDHybrid-Patcher.ps1 -Action Install -GameRoot "C:\Path\To\Kinky Dungeon" -TextureMode full

Change only the installed texture mode later:

  .\KDHybrid-Patcher.ps1 -Action Configure -GameRoot "C:\Path\To\Kinky Dungeon" -TextureMode original

The verified exact-build source optimizations are installed by default. Select
the official source files while keeping the KD Hybrid bootstrap and runtime:

  .\KDHybrid-Patcher.ps1 -Action Configure -GameRoot "C:\Path\To\Kinky Dungeon" -SourceMode original

Reapply the exact-build source optimizations later:

  .\KDHybrid-Patcher.ps1 -Action Configure -GameRoot "C:\Path\To\Kinky Dungeon" -SourceMode optimized

`-NoSourceOptimizations` remains an install-time alias for
`-SourceMode original`. Configure changes only the settings named on that
command; it does not reset pathfinding, texture, or source selection.
Configuration changes take effect after Kinky Dungeon is fully restarted.

Check it later:

  .\KDHybrid-Patcher.ps1 -Action Status -GameRoot "C:\Path\To\Kinky Dungeon"

Remove the bootstrap and restore the backed-up game files:

  .\KDHybrid-Patcher.ps1 -Action Uninstall -GameRoot "C:\Path\To\Kinky Dungeon"

The patcher refuses unknown game bundles by default. Do not bypass that check
unless you are developing and have independently verified compatibility.

MOD COMPATIBILITY

Before KD evaluates selected mod scripts, KD Hybrid scans their bounded source
text as data and asks before a high-confidence conflict. Compatibility mode
(recommended) routes only the affected optimization through KD's official
JavaScript. You can instead keep the optimization explicitly or disable that
mod for the activation without deleting its ZIP or changing KD's saved mod
list.

Remembered choices are tied to the exact mod digest and KD/Hybrid build. Change
or forget them through "Manage mod compatibility choices" in the standard
KD Hybrid mod settings.

A source-sensitive mod may require the official source bundle. Mod loading
will pause before any archive executes; close KD, configure
`-SourceMode original`, and fully restart. Selecting original source after the
page has already started cannot safely undo an installed source patch.

MANUAL RESOURCE ZIP

The default manual resource ZIP includes the exact-build optimized
out/main.js and Scripts/lib/pixi-filters.js. The separately generated
source-compatible/original variant deliberately omits both files, so copying
it onto a clean supported installation keeps the official source files. If an
optimized manual overlay was already applied, restore both official files
first; the source-compatible overlay cannot remove previously copied files.

SAVE SAFETY

The patcher does not access Electron userData or the game's save directory.
It changes resources/app/index.html and, when exact-build source optimizations
are enabled, resources/app/out/main.js and
resources/app/Scripts/lib/pixi-filters.js. It writes its own files under
resources/app/kd-hybrid and keeps byte-exact backups plus the installation
manifest under resources/app/.kd-hybrid. Uninstall verifies and restores every
original file. It also installs one owned Mods/KDHybridBridge.zip file so KD
can display Hybrid in its normal mod list and configuration screen. Uninstall
verifies that file before removing it.

Every other mod is intentionally left alone. Install those with Kinky
Dungeon's existing mod workflow.
